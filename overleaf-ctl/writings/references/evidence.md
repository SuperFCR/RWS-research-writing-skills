# 证据到正文

复用现有文献池，记录实际读到的材料层级；不要为了填表而扩展无关检索。写引言、相关工作或新的文献性论断前，先保存证据表和当前章节段落蓝图。

## .writing/evidence-map.md

每行对应一个可用的「来源—论断」配对；一篇文献支持不同论断时可有多行。

| Evidence ID | BibTeX key | 来源/DOI/URL | 已读范围与定位 | 实际发现及条件 | 可支持的论断 | 目标 TeX/段落 | 边界/状态 |
|---|---|---|---|---|---|---|---|

状态区分 verified support、indirect、unverified。存在 DOI 只能验证元数据；必须读相关内容才能写 verified support。只有标题/摘要时不能推导未读全文中的样本量、方法细节、消融结论或限制。为可追踪性记录页码、章节或具体摘录定位。

BibTeX key 使用项目已有键；新增条目由主代理统一写入现有 `.bib`。核对题名、作者、年份、出版源和 DOI/URL，不把真实 DOI 搭配猜测的题名。未解决条目留在本地档案中，不以假文献或伪造 citation key 充数。

## .writing/blueprints/<section>.md

每个计划段落写：

- 角色：背景、技术路线、限制、研究缺口、本文定位或贡献。
- 主论断与适用条件。
- Evidence ID 和实际引用键。
- 与前后段的逻辑连接。
- 不允许声称的内容及待解决问题。

写成综合论证，而非逐篇摘要堆叠。段落蓝图和证据表可以在已有材料上快速补充，不要求固定段数或引用数。研究缺口必须限定在检索和证据覆盖范围内，不能把「没有找到」表述为「从未有人研究」。

## 写后检查

核对实际 `\cite...{key}` 与 bibliography；逐项检查新论断是否仍在证据支持范围内。压缩文字时保留研究对象、条件、数据范围与局限。没有支持的强结论应削弱、移除或等待资料，不能用模糊引用装饰。审查结果和仍缺依据的点写入 `.writing/reviews/`，不污染 TeX 正文。
